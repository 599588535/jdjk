# 京东降价监控 App（安卓）

一个**不用 AutoX.js、不读屏幕**的京东降价监控安卓 App：后台定时请求京东价格接口，
低于你设定的目标价时，发**系统通知 + 微信推送**。账号专属价（PLUS/券后）通过「登录京东」获取。

## 这个 App 怎么解决之前的 bug
- **不再读京东 App 屏幕** → 改用后台 HTTP 请求京东价格接口，京东改版不会崩。
- **用系统级 WorkManager 定时** → 即使 App 被系统杀掉，到点也会被执行（解决「不会自动监控」）。
- **账号专属价**：App 内嵌登录页，登录后保存登录态，监控时优先取你的账号价。

## 你需要做什么（不用改任何代码，只上传 + 点一下）
> 全程在 GitHub 网页操作，不需要 git 命令、不需要本地编译。

### 1. 新建仓库
- 登录 GitHub → 右上角 **+** → **New repository**
- 名字随便（如 `jd-monitor`），选 **Public**
- **不要**勾选 "Add a README"（保持空仓库）→ 点 **Create repository**

### 2. 上传工程文件
- 进仓库 → **Add file** → **Upload files**
- 把本文件夹（`jd-monitor-app`）里的**全部内容**拖进去上传（保留目录结构：`build.gradle`、`settings.gradle`、`app/`、`.github/` 等）
- 拉到最下面 → **Commit changes**

### 3. 一键编译出 APK
- 点仓库顶部 **Actions** 标签 → 左侧 **Build APK** → **Run workflow** → **Run**
- 等 3~6 分钟，出现绿色 ✓ 即成功
- 点 **Build APK** → 下方 **Artifacts** → 下载 **jd-monitor-apk**（里面是 `app-debug.apk`）

### 4. 安装和使用
- 把 APK 传到手机安装（首次需允许「未知来源」）
- 打开 App：
  - 填「扫描间隔（小时）」「活跃时段」「微信提醒 SendKey/Token（可选）」
  - 点「**登录京东**」登录一次（拿账号专属价，可跳过，跳过则用公开价）
  - 「商品名 + 京东链接或商品ID + 目标价格」→「＋ 添加商品」
  - 点「**开始监控**」→ App 退到后台也会按时检查
- 底部「运行日志」实时显示每次检查结果

## 关于「账号专属价」
- 登录京东后，App 会优先用登录态请求商品页拿你的账号价；若取不到（京东页面结构变化），自动回落**公开挂牌价**并在日志标注 `(公开价)`。
- 公开价来自京东官方价格接口 `p.3.cn`，非常稳定，一定能拿到。
- 微信提醒：填 Server 酱 SendKey（sct.ftqq.com，形如 `SCTxxxxx`）或 PushPlus token（pushplus.plus）。
